# Motofix – Bike Service Mobile App

## 📱 About the Project

Motofix is a mobile application designed to help bike users find nearby mechanics and book bike repair and maintenance services easily.

The app provides a simple and convenient way to locate mechanics, view mechanic details, schedule services, make payments, track service status, and provide ratings and reviews.

## 🎯 Project Objective

The main objective of Motofix is to make bike servicing easier, faster, and more convenient by connecting users with nearby mechanics through a user-friendly mobile application.
